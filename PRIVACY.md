# Privacy Policy

Private Form Assistant runs entirely in the browser. It uses no server, telemetry, analytics, or network calls. Profile data, preferences, and optional learned fields are stored in `chrome.storage.local` and remain in the browser until you remove them.

The extension requests only `activeTab`, `scripting`, and `storage`. It has no host permissions, persistent page scripts, or background access to browsing history or websites. It runs on a page only after you click **Formu Doldur**.

The extension does not support government identifiers (including TCKN and SSN), passwords, or financial information. Do not save those values. The extension may not recognize every sensitive field, so review each field before submitting any application.

You are responsible for checking that all filled information is accurate and appropriate before submitting an application.
